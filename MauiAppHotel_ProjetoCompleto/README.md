# Hotel Horizonte — MauiAppHotel

Projeto acadêmico em **.NET MAUI** baseado no repositório MauiAppHotel indicado na atividade.

## O que foi desenvolvido

- Tela principal de contratação de hospedagem, com tema visual próprio para hotel.
- Seleção da quantidade de adultos e crianças.
- Seleção de acomodação e período de check-in/check-out.
- Validação do período e tela de resumo dos dados informados.
- Tela **Sobre**, com desenvolvedor, curso e ano de desenvolvimento.

## Estrutura

A solução `MauiAppHotel.sln` abre o projeto `MauiAppHotel/MauiAppHotel.csproj`. As páginas XAML e seus arquivos C# ficam em `MauiAppHotel/Views`.

## Observação

O aplicativo é um protótipo acadêmico de interface e fluxo de navegação. O resumo apresenta os dados digitados; não realiza reserva real, pagamento ou integração com hotel.
